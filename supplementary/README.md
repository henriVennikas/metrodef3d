# Dataset supplementary material

These optional materials document studies and measurement models built on
specific datasets generated with MetroDef3D. They are separate from the core
generator and the generator recipes in `examples/`.

- [Simple Concrete Crack Dataset](simple_concrete_crack_v1/README.md): v2
  reference data, models trained on v1.0, inference workflows and supporting
  studies. See the [v2 loading instructions](../docs/dataset-v2.md).
